- Dense SIE preparation checks a lower bound for matrix, Riesz/factor and pair
  storage against available CUDA memory before quadratic assembly allocations.
  The receipt explicitly excludes quadrature workspace and fragmentation; it
  does not promise that all later allocations fit. Capacity and injected
  allocation failures can be followed by a fresh public preparation.
