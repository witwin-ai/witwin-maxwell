# Original scalar D/K full-resource evidence contract

The opt-in original resource fixture requires all four environment values:
GSP_FIXED_FMM_ADMISSION, GSP_FIXED_FMM_ADMISSION_SHA256,
GSP_FIXED_FMM_RESOURCE, GSP_FIXED_FMM_RESOURCE_SHA256. It skips only when none
are present and rejects partial setup. Both completed original receipts are
SHA-bound; their original geometry3840, fixed-ka, selectedp11, policy, original
kernel budgets1e-6/1e-5, retained budget2GiB and table budget1GiB are checked.
Every actual new translation still independently enforces unchanged admission.

The fixture constructs the entire scalar_dk_v1 action; it compares unique native
retained inventory to recalculated exact planned bytes. It checks every other
category against the original full resource record and proves actual integrated
D/K field bytes equal both near and total storage reductions. J/M index and CSR
storage remain included. All-RHS native finite, full complex adjoint and current
backward1e-11 gates remain. It reports the dense943718400B comparison truthfully;
an action below a2GiB budget does not establish memory crossover.

Per-phase CUDA process allocator maxima are captured before every reset and after
measurement. The aggregate interval begins immediately before construction and
ends after backward and final finite/current checks. All warmups, differentiable
forward, retained earlier values and reset gaps are covered. Runtime/installed
Core/Python/Torch/device identity was recorded during execution. Measurements
exclude solve/teardown, other processes and whole-device memory; shared-GPU timing
is not N-scaling or a speedup claim. Copying the tested fixture to newer coverage
with byte equality does not numerically accept newer production differences.
