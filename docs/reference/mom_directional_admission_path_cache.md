# Guarded automatic path products

`AutomaticDirectionalDAGPlan.build_far()` binds the actual projection to the immutable plan. The projection validates canonical keys and numerically identical actual support before maps, then reuses the plan's admitted all-ancestor CUDA path products under the existing current and workspace guards. Saved native backward also validates that plan. Prescribed unguarded owners keep their original path accumulation.

The borrowed array is not a second owner cache; its planner-owned bytes still contribute to whole-resource accounting. Read `docs/assessments/sie_directional_admission_path_cache.md` for the terminal targeted precision/guard/empty-path evidence. No production qualification or whole-resource performance claim.
