# Reciprocal scalar packed near primitive

PackedReciprocalScalarNearChannels.from_layout accepts complete reciprocal physical-node pairs on identical square native complex128 J/M spaces with an explicit source_node_offset. It requires one fixed original free-space scalar medium and IntegrationConfig. All full-layout maps must agree after source namespace normalization. Capacity is checked before any original integration; retained tensors are compact and disjoint. Off-diagonal D/K kernels are integrated once and reversed by ordinary transpose, while diagonal kernels remain full. Adjoint and native current derivatives use the shared material/H action.

Reverse index scratch is bounded by action_batch; no reversed numeric arrays persist. Layout/count, identity/version, material/integration and tensor mode changes reject, including saved-current backward. This primitive does not certify arbitrary caller kernels, tensor/periodic reciprocity, full-system integration, quadrature convergence, measured peaks or resource crossover. Public FMM storage configuration and factory/capacity integration are not yet implemented for this new policy. See the phase assessment and immutable targeted collector for the limited physical/native evidence.
