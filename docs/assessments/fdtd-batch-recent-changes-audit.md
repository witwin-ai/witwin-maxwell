# Batch 最近改动审计

日期：2026-09-08。审计起点：b902bf5、c4a71a7、d12e001、7fb71e6。

## 发现与处理

1. 全域谱每轮重新分配，导致重复 Graph capture 和 O(T F) 主机表重建。R11 已改为独占槽内原址复位、标量波形完整声明缓存，并用存储代数使捕获失效。普通单场景分配语义不变。
2. 伴随快照同时复制频谱 bank 和它的逐频点 Tensor view。R11 改为单份独立 bank 和重建视图，保持已发布 tape 与可复用槽隔离。
3. 新增零长度分量描述后，原生 DFT 入口缺少全空/频点数边界拒绝。R11 增加 launch 前检查。
4. 多 worker 自动容量仍按总 N 选择 B，可能单个 worker 领取全部工作。后续容量修复与实际双卡分配测试单独记录。

场景快照和规范字段名修复保持有效。原始输入版本保护、已有公开 Result 接口与 GPU 伴随数值矩阵作为回归门。

## 边界

吞吐调优测量的是流式前向，包含 tape 创建但不执行 backward，也不证明 N 份保留输出提前放得下。调优候选会重建 SceneModule；可比较的物理工作量要求 to_scene() 给出稳定的场景声明，任意外部副作用不属于 RNG 状态恢复承诺。融合 B-lane 反向和全输出提前容量证明仍未交付。

R11 验收：最终持久频谱/非均匀网格/原生谱内核/普通伴随组合 67 passed。此前真实双卡批量组合除新增梯度逐位断言外 60 passed；该断言观测到约 1.2e-7 的相对舍入差异，改为前向逐位检查和严格的 VJP 数值容差，并在最终组合通过。存储清单确认逐频点视图不额外占用 bank 存储。
