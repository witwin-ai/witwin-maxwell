## 3. 最后独立对抗审计发现并修复的问题

三名代理分别从材料/稳定性、伴随/状态、时间/API 出发，首轮没有实现交接说明，只读检查代码并建立独立反例。发现问题后允许修复，最后相互只读复核。

### 材料算子与梯度

- 空间变化完整张量的原边上逆矩阵插值不互易：独立原生算子谱含复特征值，源关闭后场增长超过 `1e11`，将 dt 减半仍发散。改为节点逆张量及按 Yee 体积加权的互易映射，配合正的对角剩余项；均匀与非均匀网格的组装算子正定、自伴，原生转置与独立自动微分一致，长期反例保持有界。
- 原导电修正不能被称为完整耦合隐式更新。保留节点移位逆矩阵，并加入保守导电反馈步长界；强导电离散谱和时域衰减验证。
- 实际边对角材料和节点交叉逆张量都进入材料 VJP。接触/不接触设计区域、多种回放间隔和三个有限差分尺度覆盖密度导数。
- PointDipole、UniformCurrentSource、CustomCurrentSource 的电流现在通过完整逆张量注入横向 E 分量；支持周期端点和局部非周期支撑，磁流及场修正保持各自的物理定义。
- 伴随回放曾覆盖电流源图保留的逆张量叶子，导致横向源材料梯度被静默漏掉。现在回放复用静态前向 patch，反向只构建一次源图并在最终材料 VJP 汇总。强检出算例中删去该梯度导致约 **13.7%** 偏差；修复后六个源/网格算例的最大有限差分相对误差 **6.7192e-4**，低于原计划 **2e-3** 门槛；checkpoint 间隔为 1/17/61。

- `tests/gradients/test_fdtd_anisotropic_material_pullback.py`
- `tests/sources/current/test_full_tensor_current_contraction.py`

### 图捕获与持久状态组合

- 嵌入端口/电路的图捕获补齐陀螺磁状态，成功与异常路径都恢复；Mur 和 RF 混合伴随合并各自状态键。
- 恢复身份校验补上陀螺磁偏置，不能载入物理不同的偏置配置。
- 格式 4 补齐击穿状态、计时器、触发步、触发前场、触发沉积及累计耗散；恢复只重建系数，不重复推进或记热。
- 完整张量与 CPML 重叠的九个辅助历史进入物理检查点。实际落盘恢复的六个场及九个历史逐位一致；故意清空历史会改变最终 E，证明测试能检出遗漏。

永久回归：`tests/fdtd/test_state_composition_regressions.py`，12 项。

### 源、端口、电路、分布式时间语义

- 分离主源时间函数和共同归一化时间函数；场源与端口共同决定归一化、窗口和时长，保留物理幅度/相位。
- 端口频谱使用与场结果一致的绝对相位原点；E 为 `n*dt`，H 为 `(n-1/2)*dt`；精确伴随种子消费实际前向相位表。没有改动电路物理积分时间。
- 自动步长解析全部声明载频、衰减包络及有限 Pulse 上升/宽度/下降/周期和 PWL 段宽。显式 dt 仍由用户指定；理想零时长跳变不被伪装成可解析有限带宽。
- 分布式普通/伴随都配置同一个 dt、冻结规则及默认源频率；时间输出独立于频谱装包，支持 time-only，NCCL 实际双进程验证了时间戳、输出和梯度。

永久回归：`test_time_consumer_consistency.py` 的单卡与多卡版本、`test_declared_drive_frequency.py`、NCCL worker 的 `time_record` 模式。

## 5. 缓存参考比较：有实际误差，不能宣称全部达标

`python -m benchmark` 完成 **102 个场景，102 个缓存命中，0 次云端计算**；[结果表](../../benchmark/RESULTS.md)已更新。该全扫在最终独立审计修复前运行；其中唯一完整张量场景 `full_tensor_slab` 在最终前向修复后再次用正式 CLI 验证并更新。

按计划门槛，场 L2 `<0.1` 为 **60/102**；有通量测量的场景中相对误差 `<0.05` 为 **62/86**。因此仍有 **42 个场指标、24 个通量指标未达标**。

## 6. 性能和内存

[原始样本](fdtd-repair-performance-2026-09-08.json)包括基线与候选包路径、设备、三次样本和峰值。独立 GPU 窗口、每场景一次预热、600 步、三次测量。下表 ms/step 是完整 solve 耗时除以步数，含图捕获/监视器，不能冒称纯 kernel 延迟。

| 场景 | 基线 ms/step | 修复 ms/step | 基线/修复峰值 MiB |
| --- | ---: | ---: | ---: |
| 真空 32³ eager | 0.19228 | 0.23458 | 9.22 / 9.22 |
| 真空 32³ graph | 0.07814 | 0.07651 | 9.87 / 9.87 |
| 真空 96³ eager | 0.13871 | 0.18915 | 237.99 / 237.99 |
| 真空 96³ graph | 0.13811 | 0.13812 | 255.09 / 255.08 |
| 完整张量 32³ eager | 0.23111 | 0.21096 | 10.43 / 12.84 |
| 完整张量 32³ graph | 0.08852 | 0.09032 | 11.09 / 13.10 |

默认 graph 的真空 96³ 时间基本相同；完整张量 graph 约增加 2.03%，峰值约增加 2 MiB。互易四槽系数需要额外存储，已删除不必要的第二份系数副本。eager 样本调度方差较大，部分中位数增大，**本组三样本不足以认证 eager 无性能回退**。

为检查这一疑点，在代码提交 `b1bcb98` 后追加真空场景 **6000 步、一次预热、七次采样**，同一独立设备上依次运行原基线和最终代码，保存全部原始样本：

| 长采样场景 | 基线 ms/step | 修复 ms/step | 中位数变化 |
| --- | ---: | ---: | ---: |
| 真空 32³ eager | 0.141710 | 0.142987 | +0.90% |
| 真空 32³ graph | 0.059506 | 0.060080 | +0.96% |
| 真空 96³ eager | 0.161001 | 0.161819 | +0.51% |
| 真空 96³ graph | 0.133746 | 0.133805 | +0.04% |

长采样没有复现短测中明显的 eager 差距，四项中位数增加都低于 1%，峰值不变。这支持这些场景没有明显回退，不能外推为任意材料、监视器和硬件的统一性能保证。

300 步伴随 checkpoint stride 1/31/300 的峰值分别 **138.51/36.88/138.51 MiB**，梯度在 `rtol=1e-5, atol=1e-6` 内一致。首个耗时含冷启动，不据此声称某个 stride 稳态更快。

## 7. 结论边界

已确认的 FDTD 缺陷都有实现修复和对应数值/状态回归；独立复审未留下已确认的实现阻断项。全仓仍有已在基线复现的 16 个 FDFD 失败，参考精度与 eager 性能的上述验收限制仍保留。本轮交付是缺陷修复及可复核证据，不能等同于所有场景精度和性能已获完整认证。
