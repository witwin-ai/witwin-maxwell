日期：2026-10-22
状态：实施中；P0 环境与基线已绑定，P1–P12 功能及物理验收进行中。各阶段以实际证据为准。
适用仓库：以 `witwin-maxwell` 为主，按明确接口涉及 `witwin-core`、`maxwell-bench` 和应用侧适配器。
基线提交：`witwin-maxwell@10d3513`、`maxwell-bench@800077f`。
诊断依据：[assessment.json](../assessments/thin-copper-2026-10-22/assessment.json)、[薄片对照结果](../assessments/thin-copper-2026-10-22/results.json)、[公开场景重建结果](../assessments/thin-copper-2026-10-22/site-results.json)。

## 1. 最终目标与交付边界

建立可用于 PCB 传输线、印刷天线和超薄铜片的完整工作流：

`物理几何与材料 → 网格与导体/馈电审计 → Scene → Simulation → Result → 复数网络参数、功率损耗、天线指标 → 收敛和独立参考验证`。

完成的含义是：真实损耗、物理厚度、馈电、电流回路、场与端口的能量交换、远场归一化以及运行状态恢复都在同一离散模型下成立，且在声明的范围内有证据支持。短程运行、输出有限、图形看起来合理、测试被跳过、已知失败被标成预期失败，均不能代替功能验收。

分两次发布，避免用无限扩大的范围掩盖核心交付：

| 发布 | 必须交付的功能 | 完成条件 |
| --- | --- | --- |
| R1：平面 PCB 工程能力 | 轴对齐平面 PEC/有限导电薄片；分层有损介质；标准集总和终端馈电；已有波端口接入；单端/差分网络；传输线和印刷天线；完整功率核算；CUDA Graph、恢复、结果持久化 | P0–P7、P8 中 R1 项、P9、P10 全部通过 |
| R2：优化与复杂几何能力 | R1 新能力的连续参数梯度；单机空间多 GPU；斜置/曲面薄片和弯曲柔性板 | P8 剩余项、P11、P12 全部通过；独立发布相应支持矩阵 |

R1 对未实现的曲面、几何拓扑梯度或跨设备所有权组合，必须在准备阶段给出明确错误；不能自动转成有体积粗体素、忽略损耗、使用 CPU 求解，或返回零梯度。R1 完成不代表 R2 完成。

本计划不把“任意高阶拟合、任意极端网格、任意有源非线性电路都稳定”作为未经限定的承诺。每项支持均绑定材料频带、网格质量、模型阶数和执行方式。

## 2. 已确认事实、证据限制与工作假设

### 2.1 已确认的基线

| 编号 | 已确认事实 | 需要解决的问题 |
| --- | --- | --- |
| B01 | 在 0.6 mm 网格上，35 μm PEC 薄片从节点面平移半格后，PEC 约束数变为零，反射变成近乎全透射；当前 conformal 也复现 | 导体表示必须覆盖真实薄片，不能依赖体积节点碰巧落入几何 |
| B02 | 普通体电导率铜在该粗网格上的线积分电导可变为目标的约 13.07 倍，半格平移后也可归零 | 未解析体铜不能被当作厚度守恒的薄层模型 |
| B03 | 直接使用现有集总馈电时，场景任何位置的非零电导率都可触发全局拒绝 | 静态电导率与端口、电路的联合更新尚未闭合 |
| B04 | 合法柔性板电流积分轮廓经 float32 中心/尺寸换算会被网格对齐检查拒绝；float64 对照通过 | 几何精度和局部网格容差合同需要统一 |
| B05 | 公开柔性板/硬板网格已包含铜层上下界；准备所得时间步分别约 53.10 fs / 98.65 fs | 不能把这些默认输入直接归入 B01；其铜厚会限制全域时间步 |
| B06 | 12 ns 在上述网格分别需要约 225,985 / 121,646 步 | 这是由实际时间步推算的步数，尚不是对应时长的全程性能测量 |
| B07 | 默认柔性基板只有一个厚度区间，硬板只有两个；默认 PCB 仅有两个固定馈电焊盘 | 铜厚得到解析并不代表介质、馈电或完整天线已得到验证 |
| B08 | `Medium2D`、`LossyMetalMedium` 和有理表面阻抗已经存在 | 应补齐组合和物理合同，复用现有实现，避免再造一套材料运行时 |
| B09 | 既有偶极子与 patch 辐射处理流程通过；patch 匹配和正向辐射物理门仍预期失败 | 需要正确馈电、合理有限地板、覆盖实际谐振的频带与独立参考 |

### 2.2 不能从现有证据推导的结论

- 公开网站的求解请求绑定用户本机 runtime；本次没有读取其历史候选、部署适配器实现或原始运行结果。
- 公开场景重建使用原始电压线，但电流轮廓由本地按 Yee 半网格构建；这证明本地端口接口的问题，不能证明线上适配器一定采用相同轮廓。
- 15 组场景重建中的成功运行只有 128 步，用于准备和执行检查，不能证明 S11、效率、远场或稳态正确。
- 公开默认 PCB 输入尚未选中设计铜片，不能把两个焊盘的失配解释为完整天线求解失败。
- 既有 patch 基准的腔模估计约 3.391 GHz，而历史测试频带为 4.4–6.0 GHz；其失败不能作为 FDTD 方法无效的证据。
- 诊断环境实际导入的是 `maxwell` 环境中安装的 core，而非兄弟 `witwin-core` checkout；实施前必须绑定真实导入源，不能混淆版本。

### 2.3 待验证假设

H01：完整的静态导电联合更新可使有损基板与标准集总馈电正常组合。
H02：具有显式几何/电磁所有权的平面薄片可避免导体消失，同时不依赖铜厚设置最小空间步长。
H03：合适的双侧有限厚度表面模型可准确保留 GHz 铜损耗，并减少全域时间步数量。
H04：固定物理几何下改善基板和边缘分辨率，并修正馈电后，传输线和 patch 能达到后文的工程误差目标。

每项假设必须通过对应物理测试接受或被证据否定；不能通过删除失败场景、调整参考值或放宽门槛来完成。

## 4. 架构与模块责任

### 4.1 必须保持的公共架构

1. 使用现有 `Scene → Simulation → Result`，`SceneModule` 物化后进入同一编译路径。
2. 材料和结构优先通过现有 `Structure`、`Material.pec()`、`Medium2D`、表面阻抗模型表达。
3. 只有现有模型无法表达“物理厚度、双侧状态、连接关系”时才增加最小公共描述；先写 API 决策记录，再更新 `FEATURE_LIST.md`。
4. 新增描述不得创建第二套求解入口、独立端口结果容器或隐式 CPU 分支。
5. 物理铜厚、面所在坐标、有效电磁参考面、几何显示厚度和数值网格厚度必须分别记录，不能相互替代。
6. 同一场景的 forward、批次、恢复和未来 adjoint 使用同一材料与耦合所有权定义。

## 5. 核心离散合同

### 5.1 精度、网格和几何位置

- 网格节点、端口几何运算和匹配身份使用 float64；场状态可继续使用现有 GPU 精度。
- float64 输入张量经过几何构造、场景放置、序列化和重建后不得被提前降为 float32。
- 对齐容差同时考虑输入精度、坐标量级、局部 ULP 和局部间距，并设置相对最小间隙的上界。
- 对能唯一判断的表示舍入误差进行规范化；真实离网格输入必须被拒绝，或在显式允许的网格规划阶段加入相应面。
- 不使用全域大容差把两个端子、两层铜或窄槽吸附到同一个位置。
- 薄片平面若需要插入网格，应在场景网格最终确定前完成；之后同步重编译材料、端口、监视器、PML 和缓存身份。

### 5.2 PEC 薄片和连接

- 轴对齐薄片按真实支撑面与切向 Yee 边的几何关系生成约束，不能先把它变成体占据率再阈值化。
- 采用明确的边界闭合、重叠优先级、端点接触、槽口与孔洞规则；同一边只有一个最终所有者。
- 拓扑连接按真实接触及相应离散自由度建立，不使用体素膨胀连接隔着空气的两片铜。
- 已声明的馈电间隙只开放对应的物理端口自由度；相邻真实短路必须报错，不能被“开 gap”逻辑掩盖。
- 体积铜小于局部分辨率时，应要求使用薄片模型、显式细化，或报告未解析；不得静默给出错误的有效厚度。
- 当前 conformal 的逐步 E 抑制可能引入非物理损耗；不能直接复用该机制并将结果称作无损 PEC 薄片。

### 5.3 有损介质与场路耦合

- 从实际 E 更新推导端口响应，包含静态电导、双网格控制体积和相关历史状态，而非固定假设端口系数恒为 `dt / eps`。
- 删除全局 conductivity 拒绝必须以联合更新实现为前提。局部仍不支持的组合继续精确拒绝。
- 采用同一中点/离散时刻的端口 V/I、电路功和场功；源、RLC、MNA、嵌入网络不能各用不同的校正顺序。
- 色散 ADE 必须进入联合消元或等价的能量一致耦合；不能端口更新后再覆盖同一边的 ADE 校正。
- 采样与电流沉积在正确质量矩阵下互为对偶，避免在非均匀网格上凭经验缩放源。
- 有损介质远离端口与覆盖端口分别测试；不能只放开前者后宣称所有导电端口已支持。

### 5.4 铜箔表面模型

- 面电导 `σt` 只用于其有效频率/厚度范围，不能自动充当 GHz 厚铜的趋肤模型。
- 以 `t/δ`、频带、σ、μ 和两侧介质为模型输入，独立记录近似误差预算。
- 厚导体极限可使用经过验证的单侧阻抗；薄膜极限必须保留两侧场与穿透的耦合。
- 同一几何面上的两个相反法向更新不能通过覆盖顺序模拟双侧铜箔；需有统一的双侧本构与状态所有者。
- 复用已有被动有理拟合和 ADE 实现；被动拟合证书不能代替表面与 Yee 联合系统的离散稳定性验证。
- 功率采用统一峰值相量约定；铜损耗只在表面或体积中计算一次。
- 无法证明宽带有效的窄带纯电阻近似必须明确标注，不得作为宽带铜损耗的最终验收路径。

## 7. 分阶段开发与测试工作包

### P0：依赖身份和基线，G0

开发与取证：

1. 记录所有实际导入包路径、源码 hash、Git HEAD/dirty 状态、torch/CUDA/驱动、GPU、内核构建源 hash 和编译参数。
2. 比较安装 core 与兄弟 checkout。选定可复现、互相兼容的依赖组合；若需更新 core，单独提交必要修改并绑定版本。
3. 冻结已有诊断，新增运行写新目录。把脚本中的关键反例转成会检测真实错误的回归测试。
4. 保存五类公开场景输入及材料、激励、频带、初始铜片清单；把“默认草稿”和“完整候选”分成不同 fixture。
5. 为网络、功率、时间步、性能及收敛建立统一机器可读报告；数值失败不能编码成成功或缺省零值。

测试与门槛：

- GPU 预检实际分配张量并运行小型原生内核，不能只检查 `nvidia-smi`。
- B01–B04 对应错误在基线真实复现；B05/B06 从准备后的网格与 dt 重新计算。
- 所有基线输入和输出 hash 可校验；安装依赖与 checkout 来源明确。
- 现有 cache/material 20 项、benchmark 9 项、天线 2 pass/1 xfail 重新记录；任何差异有原因和原始日志。

G0：复现身份和失败签名稳定后才能开始数值修复。

### P1：坐标精度、端口和准备阶段审计，G1

开发：

1. 沿几何构造、`_box_values`、`_snap_index` 和端口编译统一精度合同，避免中心与尺寸相减导致的小量精度丢失。
2. 电流轮廓从真实非均匀半网格生成，保留电压端点、极性和物理参考面；不得假设多格 gap 的中点一定在半网格。
3. 增加准备报告：最小间距来源、实际 dt、预计步数、材料频带、端口索引、铜片保留数、连通分量、gap 状态与 PML 距离。
4. 把错误分类为“可规范化的表示舍入”“真实离网格”“拓扑冲突”“不支持材料组合”，携带具体对象和坐标。

测试：

- uniform/custom/auto；三个轴；正负坐标；局部平移与整体坐标偏置；float32 数组、float64 数组与张量。
- 重现 25 μm 边界由 float32 中心/尺寸产生偏差的案例，并验证端口身份和极性没有改变。
- 在相邻合法节点之间放置真正错误输入，必须拒绝；容差不能把 18 μm 铜层或窄 gap 合并。
- 合法输入经保存、重建、批次和重复 prepare 后产生相同规范索引与权重。
- 平移不变性测试需保持物体之间的相对位置和边界条件；不得把移动天线相对外壳后的真实物理变化判成误差。

G1：精度反例通过、错误输入仍被拒绝、所有已支持端口回归通过。

### P2：PEC 薄片、孔槽和馈电连接，G2

开发：

1. 复用材料编译层增加显式平面支撑与切向边约束，覆盖零厚度及声明为薄片的有限物理厚度输入。
2. 支持平面矩形并集/差集、孔槽和多边形；建立唯一边所有者与确定性优先级。
3. 支持地板、信号走线、过孔和已有细线探针的真实接触，保留 feed gap。
4. 明确 off-grid 行为：合法网格规划插面后重编译，或给出能力拒绝；禁止静默消失或自动增厚。
5. 输出几何保留率、导体连接图和约束预算；端口必须实际连接两个预期导体分量。

测试：

- 厚度为 0、18、35、70 μm；局部间距 0.1、0.3、0.6、1.0 mm；每格 0、0.1、0.25、0.5、0.75 偏移；xy/xz/yz 朝向。
- 无限平面法向反射；有限矩形散射；两片相接、重叠、T 接、带孔地板、CPW 窄槽、蛇形线和相邻但分离的走线。
- 自动插面前后对照：导体保留、约束切向正确、参考面变化可解释，且不生成跨 gap 短路。
- 解析无限 PEC 平面的反射测试要求 `|t| ≤ 1e-4`、去嵌入后 `|r + 1| ≤ 0.005`；物理离散表面必须被真正表示。
- 无源闭腔评估离散储能漂移及额外吸收；不能接受通过人为损耗获得的“稳定反射”。
- 旋转、曲面或低于支持尺度的孔槽在 R1 明确拒绝或报告未解析，不能在支持统计中算作通过。

G2：薄片不再静默丢失；连接与 gap 规则成立；无损和反射物理门通过。

### P3：静态导电材料、集总端口和电路，G3

开发：

1. 从带 σ 的实际场更新构造局部端口响应；更新 `FieldPortCoupling`、RLC 和现有 Norton/MNA 路径。
2. 先实现“远处有损材料、端口局部无损”，再实现端口支撑区与有损介质/导电薄片相交；分别发布能力标记。
3. 对多边有限孔径采用同一电压采样与电流沉积算子，正确使用非均匀控制体积。
4. 更新源阻抗、被动端接、多个互相耦合端口和嵌入网络，保持端口扫列与 `B = S A` 提取一致。
5. 同步新增电导耗散和端口功诊断；现有 `dt/eps` 校验应被实际离散系数验证替代，而非直接删除。

测试：

- 空间位置：远离端口、端口支撑区、端子边界、多个端口共享材料区。
- 材料：σ=0 极限、普通有损介质、低/中/高电导、`Medium2D`；扫描无量纲 `σ dt / ε` 的小、中、大区间。
- 电路：开路/短路/匹配，R、C、L、串并联 RLC，单端口源、多端口被动端接和现有 MNA 电路。
- 同一问题在 uniform/graded 网格、单边/多边 aperture、不同 dt 下的独立电路与传输线参考。
- `σ → 0` 连续回到旧无损结果；零驱动且被动电路不产生净能量；强电导下无隔步振荡型非物理长期残余。
- 实际 GPU 执行必须有非零场、非零端口响应和明确功率传递；仅 prepare 成功不算物理测试。
- 保留非线性、时变、完整张量等尚未实现组合的精确拒绝，避免用放开一个全局 flag 误开全部能力。

G3：静态电导与集总/电路组合通过网络和离散功验证；全局拒绝已由有物理依据的局部能力判断替代。

### P4：介质色散、铜箔表面阻抗和损耗，G4

开发：

1. 定义介质 `loss_tangent` 的频率合同：单频等效 σ 必须记录参考频率；宽带使用被动色散模型或显式限制频带。
2. 将受支持介质 ADE 的状态和响应纳入端口联合求解，保持当前场更新、端口、电路和 ADE 的时序一致。
3. 推导铜箔双侧本构：覆盖薄膜、过渡厚度、厚导体极限及不同两侧介质。明确 PEC、静态面电导和表面阻抗各自有效范围。
4. 复用已有有理拟合/状态空间与表面 ADE；对实际联合离散进行稳定性约束和有效阶数/网格诊断。
5. 铜厚作为物理表面参数保留；合格薄片路径不要求为铜厚或皮肤深度生成体积网格。
6. 在 `Result` 统一输出导体表面损耗、介质体损耗和模型误差/适用频带，禁止重复计量。

测试：

- 用独立有限厚度导电层传输矩阵作为参考，扫描 `t/δ = 0.01、0.1、1、3、10、30`；测试时检查连续介质模型适用性。
- 空气/空气、空气/基板、基板/基板；法向与斜入射 TE/TM；三个面朝向与法向翻转。
- 静态面电导的解析复数 r/t、σt 积分守恒；验证面法向没有错误导电率。
- 分别校验复数表面阻抗、反射、透射和吸收。厚铜 `|r|≈1` 时，反射误差很小仍可能损耗严重错误，必须单独限制吸收误差。
- 非被动拟合、越频带、过高阶/过粗网格、双侧状态覆盖冲突应拒绝；不能只做拟合点误差测试。
- 小型无源系统运行至少 10^6 步，覆盖极限厚度和适用频带边缘；完整 PCB 使用按物理时间定义的稳定性和收敛测试。
- 支持的电路绑定、材料 ADE 和表面状态的联合储能与耗散闭合。

G4：材料参数到铜损耗的整条链通过独立解析参考，且 supported 区域不存在已知被动模型发散。

### P5：分层网格、传输线、波端口和混模网络，G5

开发：

1. 网格规划分别约束最高频率下的介质波长、基板厚度、走线宽度、槽宽、端口 aperture 和金属边缘。

3. 现有准 TEM 模式、端口积分和材料平均必须使用同一 Yee 位置与截面；在多个介质厚度分辨率下验证有效介电常数。
4. 传输线延伸到实际准备后 PML 所需位置，或者使用有物理意义的显式端接；检查导体在计算边界的真实占据。

测试：

- 同轴线作为已有控制；微带线、stripline、CPW、两线差分对作为新增/加强场景。
- 无损/仅介质损耗/仅铜损耗/两者同时存在，固定物理 W/H/间隙；不能随 dx 改变物理尺寸。

- β、Z0、有效介电常数、S11/S21、衰减常数 α、互易性和功率平衡分别验收。
- 用不少于两个线长分离传播损耗与馈电失配；适用时比较解析准静态近似，但不把该近似当作所有频段的精确真值。
- 单端转混模验证差模/共模、串扰、极性与功率波归一化；不能只用对称结构证明互易性。

G5：传输线的相位、阻抗、衰减、端口归一化及网格收敛均达标。

### P9：性能和显存优化，G9

开发与测量：

1. 优先移除为铜厚/皮肤深度而设置的无必要体积网格，同时保留铜厚的物理表面响应。
2. 记录准备、材料/端口编译、Graph 捕获、逐步更新、DFT、NF2FF、结果拷贝和持久化耗时。

4. 对表面边/ADE 状态采用 GPU 常驻、预分配和按已声明拓扑批处理；避免每步 Python 按铜片循环和 GPU→CPU 同步。
5. 优化基于 profiler 的实际瓶颈；复用已有内核、拟合器、状态空间和缓存，不增加重复求解实现。

性能验收条件：

- 正确性与物理误差目标先通过；性能提升不能来自关闭损耗、改变源、减少所需物理时间或降低输出精度。
- 固定场景、GPU、输出和测量范围，至少一次预热与五次计时，保存中位数和离散范围；冷编译单列。
- 对未使用新功能的既有基准，稳态运行时间及峰值显存回归目标均不超过 5%；超出需单独解释并重新审查。
- 对薄铜路径，验收铜厚降低不再按体积 CFL 压低 dt；改变厚度仍通过损耗模型影响结果。
- 给出 18/35 μm 两个真实场景的全物理时间加速与显存变化，不能只引用理论 dt 比值。
- 本次仅移除铜顶面网格点的 CFL 估计约可将柔性板/硬板 12 ns 步数降至 90,253 / 46,410；这只是规划参考，非承诺加速，亦非精度证据。

G9：性能报告具有相同误差预算和物理时长，且新增功能不制造每步隐式主机同步。

### P11：连续参数梯度与优化，G11

开发：

- 在固定拓扑、固定网格与固定离散所有权下，补齐 σ、表面状态空间参数、介质参数和支持的电路参数梯度。

- 几何优化若需要离散选择，明确使用离散搜索；若需要连续几何梯度，另行定义并验证可微离散合同。

测试：

- 独立小问题的中心差分步长扫描和方向导数；不能只比较同一手写反向实现的两个调用路径。
- 损耗、复数 S 参数、接受功率和天线目标各有梯度检查；接近零响应处采用绝对误差门。
- `SceneModule` 参数保持原始张量连接；无 detach、零梯度或静默 fallback。
- eager/Graph/checkpoint 的梯度一致；一个小型材料或匹配网络优化任务有可解释目标改善，且最终重新做 forward 物理验证。

G11：支持范围内梯度相对误差目标 ≤1%，并有误差随差分步长变化的合理平台；不光滑点报告不可微或按声明的固定拓扑合同处理。

### P12：空间多 GPU、斜置/曲面与弯曲柔性板，G12

空间多 GPU：

- 表面边、双侧场状态、ADE 和端口有唯一 shard owner；跨分片连接显式交换所需量，避免双重注入或重复损耗。
- 同设备快速路径与跨设备路径共享物理更新；拒绝尚未实现的跨 shard 端口，不做主机搬运兜底。
- 1/2 GPU 比较复数 S、损耗、场和远场；覆盖面恰落分片边界、导体跨边界及连接变化。
- 记录通信字节、同步和性能；若无规模收益，不把多 GPU 可运行当成加速验收。

复杂几何：

- 斜面/曲面需要真正的切面面积、切向本构与稳定耦合，不能把旋转薄片退化成可能消失的节点体占据率。
- 弯曲柔性板保持真实层间距离、铜厚、曲率、馈电和局部法向；校验弯曲映射无自交和错误接触。
- 平面极限退化到 R1；大曲率、折角、孔槽、双侧材料和跨片连接有独立网格收敛。
- 参考包含平板极限、旋转等价场景和至少一个外部弯曲天线全波对照。

G12：多 GPU 和复杂几何分别验收、分别声明；一项通过不能替另一项背书。

## 9. 验收量、误差定义和初始预算

以下为实施前的初始验收目标，尚不是已达成精度。P0 应将场景、参考质量和门槛固定为配置。门槛若确需修改，先说明参考不确定度或问题条件数，并保存修改前失败证据，不能观察输出后随意调整。

| 指标 | 初始门槛 | 适用条件 |
| --- | --- | --- |
| PEC 无限面 | `|t| ≤ 1e-4`；`|r+1| ≤ 0.005` | 同一物理参考面去嵌入，入射谱充分 |
| 薄膜解析复数 r/t | 复数绝对误差 ≤0.005 | 对照独立有限厚度层参考；极小响应另报绝对底噪 |
| 表面阻抗 | 有效频带内复数相对误差 ≤2% | 非零阻抗；拟合误差与时域离散误差分别记录 |
| 解析导体吸收 | 相对误差 ≤5%，近零时绝对误差 ≤1e-6 | 避免接近 1 的反射掩盖损耗误差；底噪低于目标 |
| 传输线 β、Z0 | ≤2% | 合格参考与细化后结果，分开报告两项 |
| 传播衰减 α | ≤5% | 损耗可分辨，至少两个线长，不用失配伪装衰减 |
| 复数 S | 最大逐点绝对差 ≤0.02 | 同一源、负载、reference plane 和参考阻抗 |
| S 参数相位 | ≤3° | 仅 `|S| ≥0.1` 的有效点；其余比较复数绝对差 |
| 有限 Zin | 相对差 ≤5% | 远离开路/极点，明确归一化与绝对误差底线 |
| 谐振频率 | ≤1% | 固定物理模型，足够频率分辨率；无唯一谐振时报告全谱 |
| Q | ≤5% | 参考及频率/时间采样足以确定 Q |
| 主瓣增益/方向性 | ≤0.5 dB | 同模型、相同角网格、同极化定义 |
| 辐射/总效率 | ≤5 个百分点 | 可分辨损耗且接受功率充分，不能混用百分比相对误差 |
| 天线稳态功率闭合 | ≤3% | 包含所有损耗/输出通道与储能项；低接受功率点标无效 |
| 被动多端口 S | `σmax(S) ≤1.01` | 相同实数功率参考阻抗、入射矩阵良态及有效输入谱 |
| 梯度 | 相对误差 ≤1% | 固定离散拓扑、合理有限差分平台，零梯度另设绝对门 |

离散能量测试另行按实际可证明的储能形式定义残差：

`Renergy = ΔUfield + ΔUmaterial + ΔUcircuit + Wloss + Wout − Wsource`。

其中 PML 吸收、显式边界流出和跨端口流出不能重复计入。采用分量能量绝对值之和及已冻结的正尺度作归一化；不得除以接近零的净功。小型 float64 联合算子目标归一化残差 ≤1e-10；生产 float32 目标 ≤1e-4，长程累计界和误差随 dt 的变化分别记录。源关闭后瞬时场能可以与电路/材料储能交换，不能以“场能每步单调下降”作为错误的守恒要求。

## 10. 空间、时间、PML 和模型收敛

### 10.1 空间收敛

- 至少三个分辨率等级；保持物理几何、铜厚、孔径、端口参考面、材料模型和采样点不变。
- 分别细化基板厚度、金属边缘、馈电 gap、外部空气区，避免一次改变全部参数而无法归因。
- 同时报告原生网格结果和公共物理观测点上的结果；插值误差不能被隐藏。
- 记录每级相对独立参考误差与相邻级差；只有观察到稳定收敛区间才估计收敛阶或外推值。
- 自适应网格可能改变导体所有权，必须重做几何审计，不能直接假设更细一定更准。

### 10.2 时间与谱收敛

- 从 8/12/16 ns 开始比较复数 S、Zin、接受功率和远场，保持源与频域采样约定一致。
- 初始目标：连续两个更长时长间 `max |ΔS| ≤0.005`；天线功率和主瓣指标也分别达标。
- 高 Q 场景若未收敛，按衰减时间延长并记录预算；预算用尽返回未收敛，不能以固定 12 ns 宣称完成。
- 验证源归一化、DFT 窗和瞬态截断；宽带带边入射谱不足的点不输出有效网络指标。
- 时间步敏感性与运行时长敏感性独立检查，覆盖表面 ADE 拟合频带和高阶状态。

### 10.3 PML 与外部区域

- 至少两个 PML 层数等级和两个空气 padding 等级，必要时增加第三档确认趋势。
- 检查准备后真实计算域：材料、导体、端口与监视器相对 PML 的位置要以实际网格为准。
- 传播线的终止方式与开放天线的外部区域分别验证，不能共用未经检查的“到 Domain 边界即可”假设。
- 分离 PML、时空离散、表面模型、NF2FF 积分及独立参考误差，保留总预算和分项估计。

## 14. 主要风险与处理要求

| 风险 | 处理要求 |
| --- | --- |
| 通过扩大容差“修复”端口，却合并窄 gap | 使用精度与局部几何界；强制真实离网格和相邻层负例 |
| 删除有损拒绝后，端口仍使用无损系数 | 联合消元、逐步功验证和 σ 扫描先行，能力门最后放开 |
| 表面模型只匹配反射，损耗错几个量级 | 独立吸收、复阻抗、厚度极限和衰减测试 |
| 旧 conformal 软抑制导致非物理 PEC 吸收 | 无损储能与功率测试；不能以抑制振荡替代正确离散 |
| 高频表面拟合被动但联合离散发散 | 检查联合更新、阶数/网格适用域与长程测试 |
| 基板只有一两层但 S11 看似合理 | 固定几何下分别细化基板、边缘和 gap，与独立参考比较 |
| 馈电/地板设计不合理被误认作求解器问题 | 先验证电流路径、谐振覆盖和同模型对照，再判定误差 |
| 自动网格改变物理或梯度拓扑 | 显式重新编译身份；离散事件与连续参数梯度分开 |
| 缓存/Graph/恢复复用旧表面状态 | 每消费者隔离、严格 fingerprint、完整状态重置和恢复 |
| 应用侧悄悄关闭损耗或补 PEC | 直接 API/适配器编译后身份对照与原始物理输入回读 |
| 安装 core 与 checkout 不一致 | 记录真实导入源并固定依赖；缺失身份的性能/物理报告不验收 |
